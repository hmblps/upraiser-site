## 3. Dual theme = two climbs

| Theme | Mode | Sell | Lexicon |
|-------|------|------|---------|
| Light | **Growth** | Scale & ROI — *velocity*, summit, equipment that scales | view → velocity, peaks, 30K installs, ROAS |
| Dark | **Infrastructure** | Transparency & no fraud — *oxygen*, fixed lines, audit | drift, pipe, receipt, PROOF, CLARITY |

Same company. Same gear. Different emphasis:
- Growth Gear → **scalability** of tools  
- Infrastructure Gear → **precision / audit** of the same tools  
- Growth Craft → **closed growth loop** (creative → revenue)  
- Infrastructure Craft → **invoice defense** inside the same loop

## 7. Style rules (short)

1. **Stop slop** — no filler adverbs; specifics + metaphors that mean something.  
2. **Ogilvy** — claims with numbers (0.4ms, 180+, 32K installs) when you assert.  
3. **Active voice** — *We engineer Your ascent.*  
4. **Poetic ≠ vague** — every metaphor should map to a real mechanism.  
5. **Dual theme** — rewrite both modes when you touch a fold.

### Type & spacing (shipped CSS)

| Role | Token / class |
|------|----------------|
| Site UI | `--font-sans` / `--font-display` → Inter (self-hosted) |
| Phone feed mock | `--font-feed` → Plus Jakarta Sans |
| Viewport H1 | `.section-title` inside `.viewport-page__intro` → `--text-title-compact` |
| Label / kicker | `.section-label` · `.stat-label` · `.text-micro` |
| Body / lede | `.copy` · `.section-description` · `.panel-lede` |
| Primary CTA | `.btn-caps.btn-caps--primary` |
| Stack rhythm | `--space-*` · `--stack-*` · `--viewport-*` |

Prefer these over ad-hoc `text-xs` / `mt-3` / `px-5 py-2.5` on Basecamp pages.
