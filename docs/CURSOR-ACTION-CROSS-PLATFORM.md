# Action prompt — cross-platform component

Вставляй в чат Cursor (Cmd+L / Agent), когда нужно написать или переписать UI-компонент:

---

Проведи рефакторинг / напиши компонент с полным соблюдением правил из `.cursorrules`.

Обязательно обеспечь:
1. Кроссплатформенность: корректную работу на iOS Safari, Android Chrome, macOS и Windows.
2. Поддержку тача и мыши: размер тач-зон от 44×44px, обработку `@media (hover: hover)`, отсутствие залипания ховеров на смартфонах и отсутствие сдвигов интерфейса при открытии клавиатуры.
3. Корректный рендеринг высоты через `100dvh` и отступы под Safe Area (`env(safe-area-inset-*)`).
4. Защиту от случайного выделения текста при быстром клике/тапе.

Проверь код на ошибки и покажи итоговый вариант.

---

Связанные файлы: `.cursorrules`, `.cursor/rules/cross-platform-frontend.mdc`.
