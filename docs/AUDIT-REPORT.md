# Полный Аудит Архитектуры, Визуала и Кода (UPRAISER)

Ниже представлен глубокий аудит текущего состояния кодовой базы, производительности, ассетов и UX/UI. **Изменения в код пока не вносились**, это план для обсуждения и дальнейшего рефакторинга.

## 1. 🚨 Критичные точки (Performance & Assets)
Текущий вес папки `public/` составляет **160 МБ**, что очень много для веб-сайта. Главные "пожиратели" трафика:

- **`macbook-draco.glb` (29 МБ)** — даже с учетом Draco компрессии, 29 МБ для одной 3D-модели — это перебор. 
  - *Решение:* Прогнать через `gltf-pipeline` с более агрессивными настройками Draco (квантование нормалей/координат) или перевести текстуры внутри GLB в формат WEBP, ограничив их разрешение до 1024x1024.
- **`voyager-nasa.glb` (13 МБ)** — аналогичная ситуация.
- **`home-light-idle.mp4` / `home-dark-idle.mp4` (по 11 МБ)** — фоновые видео на главном экране. 
  - *Решение:* Их можно пережать через `ffmpeg` (как я сделал с лупами для Creative Studio, которые теперь весят 2 МБ) с параметром `-crf 28 -preset fast`.
- **`Snow005_2K-JPG_NormalGL.jpg` (8.5 МБ)** — 2K карта нормалей в JPG не должна весить столько.
  - *Решение:* Сжать в `WEBP` (вес упадет до ~1 МБ) без видимой потери качества.

## 2. 🏗 Архитектура и React Паттерны
В целом, кодовая база написана **очень качественно**. Отлично реализованы `Suspense`, ленивые загрузки (`LazySection`), используется `framer-motion` (пружинная физика везде на месте). Но есть пара мест для рефакторинга:

- **Отслеживание маршрутов (Антипаттерн):** В `GlobalSnowfall.tsx` жестко прописано `if (useLocation().pathname === "/craft") return null;`. Если появится страница `/about`, придется добавлять еще один `if`.
  - *Решение:* Создать `EnvironmentStore` (через Zustand) или использовать кастомный хук в `SiteLayout`, который читает метаданные роута.
- **TypeScript:** Найдено **38** использований `any` (в основном в рефах для Three.js и ивентах). Это ослабляет типизацию.
  - *Решение:* Заменить `any` на `THREE.Mesh`, `THREE.Group` и корректные типы событий.
- **Контексты:** `CaseModalProvider` и прочие провайдеры написаны чисто (нет инлайн-объектов `value={{...}}`, вызывающих лишние ререндеры), что очень хорошо.

## 3. 🎨 CSS и Верстка
Стилевая система слегка фрагментирована между Tailwind-классами и сырым CSS (`base.css`, `site-shell.css`, `hero.css`).

- **Z-Index Хаос:** Сейчас `z-index` раскидан по CSS-файлам (зерно `30`, хедер `50`, модалки `100`).
  - *Решение:* Вынести все z-индексы в CSS-переменные в `:root` (`--z-grain: 30`, `--z-header: 50`), чтобы легко контролировать перекрытия.
- **Hover эффекты:** Глобальное правило `@media (hover: hover)` соблюдается отлично (более 60+ корректных оборачиваний), но найдено около **93** сырых `:hover` в CSS, которые могут залипать на тач-устройствах, если они не вложены в медиа-запрос.
  - *Решение:* Быстрый проход по CSS-файлам для обертки оставшихся ховеров.
- **Mobile Viewport:** Везде используется современный `dvh` (например, `min-h-[100dvh]`), что защищает от прыжков UI при скролле на iPhone (safari bottom bar). Это огромный плюс.

## 4. ✍️ Копирайтинг и Контекст
- Сейчас на сайте **смесь русского и английского** языков ("The Agency", "Creative Studio", но при этом "На стадии покорения", "Аудитория" и т.д.).
- *Решение:* Если сайт нацелен на международный рынок (или должен выглядеть премиально), стоит либо полностью перевести всё на английский, либо внедрить простую систему локализации (i18n), где тексты лежат в отдельном JSON (или хотя бы в константах).

## 5. 🎬 Визуал и UX (Creative Studio)
- Страница `/craft` (Creative Studio) выглядит отлично, но сейчас это "тупиковая" страница. Скролла нет (как ты и просил), но пользователь может не сразу понять, что нужно нажать на "The Agency" в хедере, чтобы вернуться.
- *Решение:* Добавить кнопку `"BACK TO EXPLORE"` или иконку со стрелкой в левый верхний/нижний угол видео, чтобы дать явный UI-паттерн возврата.
